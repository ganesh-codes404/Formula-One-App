# Formula One App

Formula One app is a react native based app, that has user customizable features to get Formula One more closer to the user, making it personal and aims to use AI tools to increase user engagement and more.

## Features
- Real-time news about Formula one, with user customisable feed.
- What-if simulator, that use an LLM to generate "what if" scenarios in Formula One.
- User authentication and authorization
- Fantasy league feature.
- Responsive UI for mobile devices.
- User customisable settings.
- Winner prediction. 

## Technologies Used
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **LLM:** Llama 2.2B parameters

## Installation

### Prerequisites
- Node.js installed.
- Expo go set up.
- MongoDB instance running(not required for this repo).
